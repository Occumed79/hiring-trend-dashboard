# Source graph validation checklist

Before merge, validate the exact PR head with:

- dependency install
- strict TypeScript check
- full production Next.js build
- review-thread scan
- no unresolved source-integrity findings

Runtime source checks after deployment should verify at least one representative entity for each portal and confirm:

- multiple official boards can coexist for one entity
- shared statewide/association inventories reject off-target employers
- federal exception directories attach only to matching federal entities
- source lineage prevents NLx mirrors from inflating confidence
- source confidence distinguishes missing/failed sources from authoritative zero inventories
